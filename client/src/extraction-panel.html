Enhanced outputs

Explicit approval of the current revision is required for generation and download. Searchable raster PDF requires provider line polygons. Pixel-redacted PDF replaces pixels and omits the entire text layer, safely reconstructing PDF or image sources. Redacted text PDF reconstructs only sanitized OCR text; it does not preserve original layout. For PDF region coordinates use the 1600×2200 fitted raster dimensions; create a derivative to inspect its actual dimensions first.
